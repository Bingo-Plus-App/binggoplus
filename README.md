# Binggoplus & Binggo Plus Search Guide

An independent, mobile-friendly HTML information page covering `binggoplus`, `binggo plus`, and related app-access searches in the Philippines.

## Target information page

https://bingoplus.com/play/binggoplus_app/

## GitHub Pages setup

1. Create a public repository named `binggoplus` under `Bingo-Plus-App`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Go to **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, `main`, and `/ (root)`; save.
5. Check the Pages URL shown by GitHub. The expected pattern is `https://bingo-plus-app.github.io/binggoplus/` if the owner and repo name match.
